# Pause music

Every `.mp3`, `.m4a`, `.ogg` or `.wav` file in this folder is played by the broadcast overlay when _Pausmusik_ is
turned on on the control page (`/live/control`), shuffled, over and over. Add or remove files and deploy; nothing else
needs changing. See `../../pauseMusic.js`.

**Only royalty-free music.** YouTube recognises copyrighted music in a live stream (Content ID) and may interrupt it
or mute the replay. Use tracks from YouTube's own Audio Library (YouTube Studio → Audio library), filtered on
_Attribution not required_, which are free to use on the club's channel.

Keep the files small (a few MB each, 128–192 kbit/s MP3 is plenty): they are part of the site.
